# Klygen

Klygen é um projeto de gerenciamento de tarefas inspirado em ferramentas como Trello e Jira.

## 📳 Tecnologias

- HTML5
- CSS3
- JavaScript (Em desenvolvimento)
- Flask (Em desenvolvimento)

## 📌 Funcinalidades Atuais

- Sidebar
- Header
- Board Kanban
- Cards de tarefas

## 🎯 Objetivo

Este projeto faz parte do meu portifólio de desenvolvimento e será evoluído continuamente com novas funcionalidades.

## 📅 Próximas implementações

- Drag and Drop
- Login de usuários
- Banco de dados SQLite
- API com Flask
- Responsividade
